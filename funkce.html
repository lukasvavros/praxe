Vlastní funkce v jazyce C

Praxe – Arduino | Obecné informace · parametry, návratové hodnoty a praktické příklady

Vlastní funkce ti pomohou zjednodušit i delší programy pro Arduino. Na příkladech uvidíš, co znamená void, jak se předávají parametry a proč se používá return.

Co je vlastní funkce?

Funkce je pojmenovaná část programu, která provádí určitý úkol. Můžeš ji zavolat na více místech programu, aniž bys znovu opisoval stejný kód. Díky tomu je program kratší, přehlednější a chyby se lépe opravují.

Přehlednější program

Každý úkol má vlastní pojmenovaný blok.

Opakované použití

Stejný postup stačí napsat jednou.

Jednodušší opravy

Změnu provedeš v jediné funkci.

Modularita

Větší program rozdělíš na menší části.

Funkce může mít název, parametry (údaje na vstupu) a návratovou hodnotu (výsledek).

1. Voláníobsah_obdelniku(5, 10)
→
2. Výpočet5 × 10
→
3. Výsledek50
Souvislost s Arduinem: setup() a loop() už jsou funkce. Vlastní funkci si vytvoříš stejně, jen jí dáš jiné jméno.

Jak se zapisuje funkce v C?

Obecný zápis vypadá takto:

Stavba funkce
navratovy_typ nazev_funkce(typ parametr) {
  // prikazy
  return vysledek; // jen pokud funkce vraci hodnotu
}

Návratový typ

void = funkce nic nevrací, int = vrací celé číslo.

Název funkce

Například pozdrav nebo obsah_obdelniku.

Parametry

Hodnoty uvnitř závorek, které funkce dostane při zavolání.

Tělo funkce

Příkazy v závorkách { }, které se provedou.

1. Funkce bez parametru a návratové hodnoty

Chceme na sériový monitor vypsat pozdrav. Funkce pozdrav() nepotřebuje žádné údaje a nic nevrací. Typ void před názvem znamená „bez návratové hodnoty“; void v závorkách znamená „bez parametrů“.

Příklad z podkladu · pozdrav
void pozdrav(void) {
  Serial.println("Dobrý den!");
}

void setup() {
  Serial.begin(9600);
}

void loop() {
  pozdrav();   // zavolani funkce
  delay(1000);
}
Co se stane? Arduino každou sekundu zavolá pozdrav(), která vypíše text. Samotný zápis funkce ji nespustí – spustí se až při volání pozdrav();.

2. Funkce s parametrem

Funkce může dostat údaj zvenčí. Například místo stále stejného pozdravu jí předáš jméno. Parametr char jmeno[] přijímá textový řetězec.

Příklad z podkladu · jméno jako parametr
void pozdrav(char jmeno[]) {
  Serial.print("Dobrý den ");
  Serial.print(jmeno);
  Serial.println("!");
}

void setup() {
  Serial.begin(9600);
}

void loop() {
  pozdrav("Horymíre");
  pozdrav("Petro");
  delay(1000);
}

Při volání pozdrav("Petro") se text "Petro" předá do parametru jmeno. Funkce se vykoná s touto konkrétní hodnotou.

Nezaměňuj: Parametr je proměnná uvedená v definici funkce (jmeno), argument je hodnota předaná při volání ("Petro").

3. Funkce s návratovou hodnotou

Funkce nemusí jen vypisovat. Může vrátit hodnotu, kterou program dále použije. Příkaz return předá výsledek volajícímu kódu a zároveň ukončí právě vykonávanou funkci.

Příklad z podkladu · obsah obdélníku
int obsah_obdelniku(int sirka, int vyska) {
  int vysledek = sirka * vyska;
  return vysledek;
}

void setup() {
  Serial.begin(9600);
}

void loop() {
  int sirka = 5;
  int vyska = 10;
  int obsah = obsah_obdelniku(sirka, vyska);
  Serial.print("Obsah obdélníku: ");
  Serial.println(obsah);
  delay(1000);
}

int před názvem říká, že funkce vrátí celé číslo. Při volání obsah_obdelniku(5, 10) jsou parametry sirka = 5 a vyska = 10; funkce vrátí 50.

Důležité: Serial.println(vysledek) pouze vypíše číslo. return vysledek; ho vrátí do místa volání, takže s ním můžeš dál počítat.

Vyzkoušej předávání parametrů

Změň šířku a výšku obdélníku. Simulace ukáže, jaké hodnoty funkce dostane a co vrátí. Jde o výukovou simulaci v prohlížeči, nikoli o spuštění programu na Arduinu.

Interaktivní ukázka · obsah_obdelniku(sirka, vyska)
Volání: obsah_obdelniku(5, 10) Parametry: sirka = 5; vyska = 10 return 5 * 10; Výsledek: 50

Praktické úlohy

Zadání vycházejí z výukového PDF. Řešení si nejprve napiš sám.

Úloha 1 · z podkladu

Blikání LED pomocí funkce

Vytvoř funkci void blikej(int pocet_bliknuti), která blikne vestavěnou LED na pinu 13 tolikrát, kolik zadáš. Například blikej(5); způsobí pět bliknutí. Periodu blikání si zvol sám.

Ověření: blikej(3) způsobí tři bliknutí; blikej(5) pět.
Úloha 2 · z podkladu

Měření vzdálenosti

Napiš funkci zmer_vzdalenost() pro ultrazvukový senzor. Funkce musí změřit vzdálenost a vrátit ji v centimetrech, aby se výsledek dal použít v dalších příkazech.

Ověření: V hlavním programu ulož návratovou hodnotu do proměnné a vypiš ji do sériového monitoru.
Zapojení senzoru: Konkrétní piny a způsob měření závisí na typu použitého ultrazvukového modulu. Před programováním ověř jeho zapojení.

Kontrolní otázky

Nejprve si odpověz sám, potom odpověď rozbal.

1. Proč vytváříme vlastní funkce?
Odpověď

Abychom program rozdělili na přehledné, opakovaně použitelné části.

2. Co znamená void před názvem funkce?
Odpověď

Že funkce nevrací žádnou hodnotu.

3. Co znamená void v závorkách pozdrav(void)?
Odpověď

Funkce nepřijímá žádné parametry.

4. Jaký je rozdíl mezi parametrem a argumentem?
Odpověď

Parametr je název vstupní proměnné v definici, argument je konkrétní předaná hodnota při volání.

5. Co udělá return?
Odpověď

Vrátí výsledek do místa volání a ukončí danou funkci.

6. Jaký výsledek dá obsah_obdelniku(5, 10)?
Odpověď

Vrátí hodnotu 50.

7. Je Serial.println() totéž jako return?
Odpověď

Ne. println vypíše hodnotu, return ji předá volajícímu kódu.
