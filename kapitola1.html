Kapitola 1: Úvod do Arduina

Praxe – Arduino | 3. ročník

Po nastudování této kapitoly budete schopni:

  • vysvětlit, co je Arduino a jak spolu souvisejí vstupy, program a výstupy;
  • rozpoznat základní části desky Uno, digitální piny a GND;
  • vybrat desku a port, ověřit program a nahrát jej do Arduina;
  • vysvětlit rozdíl mezi funkcemi setup() a loop();
  • zapojit LED se sériovým rezistorem a určit její anodu a katodu;
  • použít pinMode(), digitalWrite() a delay() k řízení jedné i více LED;
  • odesílat text a hodnoty do sériového monitoru a vysvětlit jednoduchý cyklus nebo přetečení proměnné byte;
  • najít nesoulad mezi zapojením, čísly pinů, příkazy a komentáři v programu.

V této kapitole se seznámíte s deskou Arduino Uno a prostředím Arduino IDE. Od prvního nahrání programu přejdete k ovládání LED a k zobrazování údajů v sériovém monitoru.

Při práci propojujte zapojení s programem: sledujte, ke kterému pinu vede vodič, jak je pin nastavený a co způsobí jednotlivé příkazy. U animací nejprve odhadněte výsledek a teprve potom si jej ověřte.

Co je to Arduino?

Arduino je platforma pro výuku a vývoj elektronických projektů. Z hardwarového pohledu jde o desku s mikrokontrolérem, ke které lze připojit senzory, motory, světla, displeje a další komponenty. Tyto komponenty potom ovládáme pomocí programu vytvořeného v jazyce C++.

Arduino je vhodné pro začátečníky i pokročilé. Používá se například v domácí automatizaci, měření, robotice nebo při tvorbě vlastních zařízení.

Zapamatujte si: Arduino propojuje elektroniku a programování. Program vyhodnocuje vstupy a podle nich ovládá výstupy.

Hardware – Arduino UNO

Existuje mnoho typů Arduino desek. Liší se výkonem, počtem pinů, pamětí a možnostmi komunikace, například přes WiFi nebo Bluetooth. V hodinách budeme používat především Arduino UNO s mikrokontrolérem ATmega 328.

Mikrokontrolér ATmega 328
Taktovací frekvence 16 MHz
Flash paměť 32 KB
SRAM 2 KB
EEPROM 1 KB
Piny Digitální piny, analogové vstupy a napájecí piny.

Základní části desky

Mikrokontrolér: vykonává program uložený v paměti desky.
USB port: slouží pro programování desky a napájení z počítače.
Digitální piny: používají se pro práci se stavem HIGH a LOW.
Analogové piny: slouží například pro čtení hodnot čidel.
GND: společný záporný bod zapojení.
5 V / 3,3 V / VIN: piny pro napájení připojených součástek.

Princip fungování embedded systémů

Slovo embedded označuje systém, který je součástí určitého zařízení. Mikrokontrolér v ledničce, automobilu nebo robotu vykonává konkrétní úkol podle programu, který je v něm uložen.

Práce s aplikací Arduino IDE

Ověření programu

Tlačítko Ověřit (Verify) se symbolem fajfky najdete v levém horním rohu Arduino IDE. Spustí překlad programu a zkontroluje, zda kód neobsahuje chyby bránící překladu, například syntaktické chyby.

  1. V Arduino IDE vyberte používanou desku, v této kapitole Arduino Uno.
  2. Klikněte na Ověřit a počkejte na dokončení překladu.
  3. Pokud IDE ohlásí chybu, přečtěte si hlášení, opravte kód a ověření zopakujte.
Zapamatujte si: Ověřit program nepřenáší do desky. K tomu slouží tlačítko Nahrát (Upload) se šipkou doprava. Úspěšný překlad ještě nezaručuje, že se program bude chovat podle zadání.

Nahrání programu do desky

Pomocí tlačítka Nahrát (Upload) v prostředí Arduino IDE lze zkompilovaný program nahrát do připojené Arduino desky. Tlačítko má symbol šipky doprava a nachází se vedle tlačítka Ověřit.

  1. Připojte Arduino k počítači pomocí USB kabelu, který umožňuje přenos dat.
  2. V Arduino IDE vyberte desku Arduino Uno a port, ke kterému je připojená.
  3. Klikněte na Nahrát. IDE program přeloží a následně přenese do desky.
  4. Počkejte na hlášení o úspěšném nahrání. Arduino poté začne nový program vykonávat.
Zapamatujte si: Nahráním nového programu se nahradí předchozí program uložený v desce. Pokud nahrávání selže, zkontrolujte připojení USB kabelu, vybranou desku a port.

Výběr portu

Pomocí nabídky Výběr portu (Select Port) lze zvolit správný komunikační port, ke kterému je Arduino deska připojena. Nabídka zobrazuje dostupné porty a rozpoznané připojené desky.

  1. Připojte Arduino k počítači pomocí datového USB kabelu.
  2. Rozbalte nabídku pro výběr desky a portu v horní liště.
  3. Vyberte port odpovídající připojené Arduino desce.
  4. Zkontrolujte, že je vybraný také správný typ desky, v této kapitole Arduino Uno.
Tip: Pokud nevíte, který port patří Arduinu, odpojte desku a porovnejte seznam portů. Po opětovném připojení vyberte port, který se znovu objeví.

Sériový monitor

Pomocí nástroje Sériový monitor (Serial Monitor) v prostředí Arduino IDE můžete zobrazovat textová data, která Arduino deska odesílá přes sériovou linku do počítače. Tento nástroj slouží k ladění programů, sledování hodnot proměnných nebo komunikaci mezi uživatelem a deskou v reálném čase.

  1. Připojte Arduino k počítači a vyberte správnou desku a port.
  2. Nahrajte program, který spouští sériovou komunikaci pomocí Serial.begin(9600); ve funkci setup().
  3. Otevřete Sériový monitor pomocí ikony v pravém horním rohu Arduino IDE.
  4. Nastavte rychlost na 9600 baudů, aby odpovídala hodnotě uvedené v programu.
  5. Sledujte zprávy odesílané pomocí Serial.print() nebo Serial.println().
Zapamatujte si: Rychlost nastavená v Sériovém monitoru musí odpovídat hodnotě v příkazu Serial.begin(). Vstupní pole umožňuje také odeslat zprávu do desky. Aby na ni Arduino reagovalo, musí program obsahovat kód pro příjem a zpracování sériových dat.

Psaní programu pro Arduino

Program pro Arduino obsahuje dvě základní funkce: setup() a loop(). 

// Sem patří knihovny, konstanty a proměnné.

void setup() {
  // Kód v této funkci se provede pouze jednou po spuštění Arduina.
}

void loop() {
  // Hlavní kód programu se stále opakuje dokola.
}
setup()
Slouží například pro nastavení pinů, spuštění sériové komunikace nebo inicializaci knihoven.
loop()
Obsahuje hlavní část programu, která se neustále opakuje, dokud je Arduino zapnuté.

Blikání LEDkou na desce Arduina

Přímo na desce Arduina je jedna LED, kterou můžeme z programu ovládat. Je připojena na pin 13. Co budeme potřebovat?

Touto funkcí nastavíme pin 13, kde je připojena LEDka, jako výstup. 

pinMode(13, OUTPUT);

Touto funkcí přivedeme na pin 13 logickou jedničku (HIGH). Tím se na pin připojí 5 V a LEDka se rozsvítí. 

digitalWrite(13, HIGH); // zapnutí LED

Protože mikroprocesor v Arduinu pracuje s frekvencí 16 MHz, tak pokud bychom jen neustále měnili stav na pinu, nebylo by blikání pro lidské oko viditelné. Proto přidáme pauzu, aby oko stihlo vnímat, že LEDka svítí. 

delay(1000); // čekání po dobu jedné sekundy

Vyzkoušejte blikání LED na desce

Výuková simulace programu Blink · vestavěná LED L na pinu 13.

HIGH · LED svítíČekání: 1000 ms
void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);  delay(1000);
  digitalWrite(13, LOW);  delay(1000);
}

Zvýrazněný řádek ukazuje právě probíhající čekání. Zelená LED ON svítí trvale.

Celý program blikání LEDkou

// sem přijde vložení knihoven, inicializace proměnných...
int led = 13;

void setup() {
  // zde vložte kód, který má běžet pouze jednou
  pinMode(led, OUTPUT);
}

void loop() {
  // zde vložte hlavní kód, který se bude opakovat donekonečna
  digitalWrite(led, HIGH); // zapnutí LED
  delay(1000); // čekání po dobu jedné sekundy

  digitalWrite(led, LOW); // vypnutí LED
  delay(1000); // čekání po dobu jedné sekundy
}

LED dioda – základní informace

LED je zkratka pro Light Emitting Diode, tedy diodu emitující světlo. Jde o polovodičovou součástku, která při průchodu elektrického proudu přeměňuje elektrickou energii na světlo.

Princip fungování

LED dioda obsahuje PN přechod. Pokud jí prochází proud v propustném směru, elektrony přecházejí z vrstvy typu N do vrstvy typu P. Při jejich rekombinaci s dírami se uvolňuje energie ve formě fotonů, tedy světla.

Barva vyzařovaného světla závisí na použitém polovodičovém materiálu. Intenzita svitu se mění podle velikosti proudu, který diodou prochází.

Anoda (+)
Delší vývod LED. Připojuje se přes rezistor ke kladnému napětí nebo k digitálnímu pinu Arduina.
Katoda (−)
Kratší vývod LED. Připojuje se k zápornému pólu zdroje nebo na GND. U běžné LED bývá označena také zploštělou stranou pouzdra.
Důležité: LED propouští proud pouze jedním směrem. Při zapojení je nutné použít sériový rezistor, který omezuje proud a chrání LED před poškozením.

Přidání další LED a nepájivé pole

Na desce Arduina je jen jedna LEDka, kterou můžeme ovládat (pokud nepočítáme LEDky na pinech Tx a Rx, které ale využíváme k programování Arduina). Zkusíme si teď připojit další LEDku s pomocí nepájivého pole. Nesmíme zapomenout na sériový odpor. Jak spočítat jeho velikost?

Nepájivé pole je univerzální montážní deska určená k sestavování a testování elektronických obvodů bez nutnosti pájení. Je tvořeno plastovým tělem s hustou sítí otvorů, pod nimiž jsou vodivě propojené řady a sloupce. Ty umožňují jednoduché elektrické spojení mezi vloženými vodiči a součástkami.

Struktura pole je obvykle rozdělena na dvě hlavní části:

  • Střední pracovní oblast – slouží k osazování integrovaných obvodů a dalších pasivních nebo aktivních prvků.
  • Boční napájecí lišty – jsou označené jako „+“ a „−“ a slouží k přivedení napájecího napětí.

Při zapojování externí LED je nutné použít sériový rezistor. Ten omezuje proud, který LED prochází, a chrání ji před poškozením.

Poznámka: Anodu LED připojujeme přes rezistor k digitálnímu pinu. Katodu LED připojujeme na GND.

Úkol 1

  1. Zapojte do nepájivého pole LEDku s rezistorem. Připojte anodu LEDky na některý digitální pin Arduina (vyberte jeden z pinů 2-12). Napište program tak, aby se vždy po 1s střídavě rozsvěcovala LEDka na Arduino desce (na pinu 13) a LEDka na nepájivém poli.
  2. V posledním kroku se budou střídávě rozsvěcovat všechny 3 LED diody.

Vyzkoušej chování obvodu a napiš program. Řešení si zobraz až po domluvě s vyučujícím.

Řešení: dvě LED

const int cervena = 3;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(cervena, OUTPUT);
  pinMode(2, OUTPUT);
  digitalWrite(2, LOW);  // Zelená LED zatím zůstává zhasnutá.
}

void loop() {
  digitalWrite(cervena, LOW);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  digitalWrite(cervena, HIGH);
  delay(1000);
}
const int cervena = 3;
const int zelena = 2;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(cervena, OUTPUT);
  pinMode(zelena, OUTPUT);
}

void loop() {
  digitalWrite(zelena, LOW);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  digitalWrite(cervena, HIGH);
  delay(1000);

  digitalWrite(cervena, LOW);
  digitalWrite(zelena, HIGH);
  delay(1000);
}

Ve schématu má každá externí LED vlastní rezistor. Vestavěnou LED najdeš na desce u označení L.

Sériová linka

Sériová linka umožňuje posílat data mezi Arduinem a počítačem. V Arduino IDE se přijaté zprávy zobrazují v nástroji Sériový monitor.

  • Serial.print("text"); – vypíše text do sériového monitoru.
  • Serial.print(promenna); – vypíše hodnotu proměnné.
  • Serial.println(); – vypíše text nebo hodnotu a přejde na nový řádek.

Příklad programu

int cislo = 5;

void setup() {
  Serial.begin(9600);
}

void loop() {
  Serial.print("Hodnota promenne cislo je: ");
  Serial.println(cislo);
}

Animace sériového výpisu

Sledujte zvýrazněný řádek programu a odpovídající výpis do Sériového monitoru. Animaci můžete pozastavit nebo procházet po jednotlivých krocích.

Úkoly k sériové lince

  1. Do programu s blikáním LED přidejte výpis stavů „svítí“ a „nesvítí“ pomocí Serial.println().
  2. Napište program, který stále zvyšuje hodnotu proměnné a odesílá ji do sériového monitoru. Upravte datový typ nebo přírůstek tak, aby došlo k přetečení.
  3. Pomocí cyklu vypište do sériového monitoru čísla od 0 do 15 včetně.
  4. Pomocí cyklu vypište do sériového monitoru čísla od 10 do −5.
  5. Pomocí cyklu vypište sudá čísla od 2 do 20 včetně.
  6. Vytvořte program: po spuštění 2 s čeká, potom 1 s svítí LED, následně 25× blikne LED v intervalu 200 ms zapnuto a 200 ms vypnuto. Potom LED zhasne a zůstane zhasnutá.

Průvodce studiem:

      
Začněte tím, že vlastními slovy vysvětlíte rozdíl mezi funkcemi setup() a loop(). Potom si projděte program blikání LED a u každého příkazu popište, co udělá. Časy zadané v milisekundách převeďte na sekundy.

      
Propojte program se skutečným zapojením. Zkontrolujte číslo pinu, jeho nastavení jako výstupu, orientaci LED, sériový rezistor a spojení s GND. U nepájivého pole si nejprve určete, které otvory jsou elektricky propojené.

      
U animací nejdříve odhadněte chování LED nebo výpis v sériovém monitoru, pak svůj odhad ověřte. Program si zkuste napsat samostatně a ukázkové řešení použijte až pro porovnání. Nakonec odpovězte na kontrolní otázky bez otevření odpovědí a vraťte se k tématům, ve kterých si nejste jistí.

              LED vypne.
            


            

              Pro zapnutí používáme:
            


            
digitalWrite(led, HIGH);

            6.

13. K čemu slouží funkce void setup() a kolikrát se spustí?
Odpověď
setup() se spustí jednou po zapnutí nebo resetu. Slouží k úvodnímu nastavení, například režimů pinů pomocí pinMode() nebo sériové komunikace pomocí Serial.begin(). Potom se opakuje loop().


14. Katoda je delší vývod LED. Připojuje se přes rezistor ke kladnému napětí nebo k digitálnímu pinu Arduina. Pravda / Lež?
Odpověď
Lež. U běžné vývodové LED je katoda obvykle kratší vývod; pouzdro u ní bývá zploštělé. V našem zapojení vede na GND. Anoda je obvykle delší vývod a vede přes rezistor k digitálnímu výstupu. U zkrácených vývodů se řiďte značením pouzdra nebo dokumentací součástky.


15. digitalWrite(led, HIGH); // vypnutí LED — je komentář správný pro LED zapojenou anodou přes rezistor k výstupu a katodou na GND?
Odpověď
Ne. Při nastavení pinu jako OUTPUT stav HIGH tuto LED rozsvítí. Správný komentář je // zapnutí LED. Samotný komentář chování programu neovlivňuje.


16. Jaký příkaz pozastaví běh hlavní části programu na zadaný počet milisekund? Uveďte příklad pro dvě sekundy.
Odpověď
Použijeme delay(). Jedna sekunda má 1000 milisekund.
delay(2000);


17. Nakreslete schématickou značku LED diody. Co znamenají dvě šipky u značky?
Odpověď
Značka LED je značka diody doplněná dvěma šipkami směřujícími ven, které znázorňují vyzařované světlo. Příčná čárka značí katodu.


18. Je program správný ve srovnání se zapojením? Najděte chyby v číslech pinů, nastavení i komentářích.
const int LED1 = 13;
const int LED2 = 6;

void setup() {
  pinMode(LED1, OUTPUT);
  pinMode(LED2, INPUT);
}
void loop() {
  // Rozsvítí LED2, zhasne LED1
  digitalWrite(LED1, HIGH);
  digitalWrite(LED2, LOW);
  delay(1000);

  // Zhasne LED1, rozsvítí LED2
  digitalWrite(LED1, LOW);
  digitalWrite(LED2, HIGH);
  delay(1000);
}
Odpověď
Ve schématu je LED1 na D3 a LED2 na D2. Konstanty 13 a 6 tedy neodpovídají vodičům. Oba piny musí být výstupy. První komentář je obráceně: příkazy rozsvěcují LED1 a zhasínají LED2. Druhý komentář odpovídá příkazům.
const int LED1 = 3;
const int LED2 = 2;

void setup() {
  pinMode(LED1, OUTPUT);
  pinMode(LED2, OUTPUT);
}
V první části loop() změňte komentář na // Rozsvítí LED1, zhasne LED2. Zbytek posloupnosti může zůstat.


19. Je LED v nepájivém poli zapojená správně? Vysvětlete chyby a navrhněte opravu.
Odpověď
Ne. Oba vývody LED jsou zasunuté do stejné elektricky propojené skupiny pěti otvorů, takže mezi nimi nevznikne potřebné napětí. Navíc napájecí lišta, na kterou vede spodní propojka, nemá v obrázku spojení s GND Arduina.
Každý vývod LED přesuňte do jiné propojené skupiny. Vytvořte cestu digitální výstup → rezistor → anoda LED → katoda → GND. Pokud používáte zemní lištu, propojte ji s GND desky.


20. Jaký je rozdíl mezi tlačítky Ověřit a Nahrát v Arduino IDE?
Odpověď
Ověřit přeloží program a zjistí chyby bránící překladu. Nahrát program přeloží a přenese do vybrané desky přes zvolený port. Úspěšný překlad sám o sobě neznamená, že program dělá to, co požadujete.


21. Co nastavíte v Arduino IDE před nahráním a co zkontrolujete, když se nahrání nedaří?
Odpověď
Vyberete správnou desku a komunikační port. Zkontrolujete připojení, USB kabel schopný přenosu dat, správnou volbu portu a konkrétní chybové hlášení IDE.


22. Jak se liší Serial.print() a Serial.println()? K čemu slouží Serial.begin(9600)?
Odpověď
print() vypíše údaj bez ukončení řádku. println() za údaj přidá ukončení řádku. Serial.begin(9600) zahájí sériovou komunikaci s nastavenou rychlostí; v monitoru zvolte odpovídající rychlost 9600 baudů.


23. Co vypíše tento cyklus? Kolikrát se jeho tělo provede?
for (int i = 0; i <= 15; i++) {
  Serial.println(i);
}
Odpověď
Vypíše čísla 0 až 15 včetně, každé na samostatný řádek. Tělo se provede 16krát. Podmínka i < 15 by skončila u hodnoty 14.


24. Jaké hodnoty vypíše tento program a proč?
byte cislo = 254;
for (int i = 0; i < 4; i++) {
  Serial.println(cislo);
  cislo++;
}
Odpověď
Vypíše 254, 255, 0 a 1, každou hodnotu na nový řádek. Typ byte má rozsah 0–255. Při zvýšení 255 o jedna dojde k přetečení a hodnota se vrátí na 0.


25. Kam umístíte sekvenci „2 s čekání, 1 s svícení, 25 bliknutí a konec“, aby se provedla jen jednou? Jak dlouho trvá?
Odpověď
Po nastavení výstupu ji umístíte do setup(); funkci loop() můžete nechat prázdnou. Na konci nastavíte LED na LOW.
Celkem jde o 2 + 1 + 25 × (0,2 + 0,2) = 13 sekund zadaných prodlev. Pokud sekvenci bez další podmínky vložíte do loop(), bude se opakovat.
