Kapitola 11: Sériová komunikace

Praxe – Arduino | 3. ročník · UART, LCD, servo a dvě Arduina

Po nastudování této kapitoly budete schopni:

  • Vysvětlit základní princip sériové komunikace a význam pinů TX a RX.
  • Spustit sériovou linku a zjistit dostupná data pomocí Serial.available().
  • Přijímat text přes Serial.readString() a zobrazovat jej na LCD.
  • Načíst číslo přes Serial.parseInt() a řídit polohu serva.
  • Správně propojit dvě Arduina přes UART a společnou zem.
  • Přenášet hodnoty potenciometrů a ovládat tři barevné složky RGB LED.

Klíčová slova kapitoly:

UART, sériová komunikace, TX, RX, GND, baud rate, Serial.begin(), Serial.available(), přijímací buffer, Serial.readString(), Serial.parseInt(), timeout, Serial Monitor, LCD I²C, servo, RGB LED, analogRead(), PWM.

Arduino může přes sériovou linku přijímat pokyny z počítače, odesílat naměřené hodnoty a komunikovat s jinou deskou. V této kapitole si postupně vyzkoušíš text, čísla i přenos tří barevných složek.

Co je sériová komunikace a UART?

Sériová komunikace přenáší bity postupně v čase. Rozhraní UART (Universal Asynchronous Receiver-Transmitter) používá pro vysílání pin TX a pro příjem pin RX. Asynchronní komunikace znamená, že vysílač a přijímač nepotřebují samostatný vodič hodin; musí se však shodnout například na přenosové rychlosti.

Vysílání

TX

Odesílá data z Arduina do druhého zařízení.

Příjem

RX

Přijímá data ze zařízení do Arduina.

Společná reference

GND

Pro propojené UART moduly se společnou signalizací musí mít obě desky společnou zem.

Rychlost

9600 Bd

Obě strany nastav na stejnou rychlost. U běžného UART rámce je 1 symbol = 1 bit.

Zapamatuj si: Serial.begin(9600); nastaví rychlost sériové linky. V sériovém monitoru počítače zvol stejnou hodnotu (9600 baudů). Při neodpovídajícím nastavení mohou být data nečitelná.

Funkce Serial.available()

Serial.available() vrací počet bajtů, které už dorazily do přijímacího bufferu a čekají na přečtení. Je to způsob, jak nejprve ověřit, zda má smysl číst data pomocí Serial.read(), Serial.readString() nebo Serial.parseInt().

HodnotaCo znamenáDalší krok
0Žádné čekající bajtyPokračuj v běhu programu
> 0V bufferu jsou přijatá dataPřečti bajt, text nebo číslo
Samostatné procvičení

Zkus vlastními slovy vysvětlit, co se stane, když je přijímací buffer prázdný a kdy může program začít číst. V závěrečné úloze si pak napiš vlastní program pro příjem jednotlivých znaků.

Pozor na rozdíl: available() počítá bajty, nikoli nutně zobrazované znaky. Například některá česká písmena v UTF-8 zabírají více bajtů. Samotná funkce data z bufferu neodstraní.

Serial.readString() – přijímání textu a LCD

Funkce Serial.readString() přijme data ze sériové linky jako text (String). Pokud další data nepřicházejí, čtení skončí po nastaveném časovém limitu (timeout). Proto může program krátce čekat. Pro příkazy ukončované znakem nového řádku je často vhodnější Serial.readStringUntil().

Příklad z podkladu · přijatou zprávu odešli zpět
String text_vstup;

void setup() {
  Serial.begin(9600);
}

void loop() {
  if (Serial.available() > 0) {
    text_vstup = Serial.readString();
    Serial.print("Vase zprava: ");
    Serial.println(text_vstup);
  }
}

Serial.parseInt() – přijímání čísel a servo

Serial.parseInt() hledá v přijatých datech celé číslo a vrací jeho číselnou hodnotu. Může přeskočit počáteční jiné znaky; po uplynutí timeoutu může vrátit 0, což není totéž jako správně zadaná nula. Proto je pro spolehlivou kontrolu textového příkazu vhodné doplnit i kontrolu formátu.

Příklad z podkladu · přijetí celého čísla
int cislo_vstup;

void setup() {
  Serial.begin(9600);
}

void loop() {
  if (Serial.available() > 0) {
    cislo_vstup = Serial.parseInt();
    Serial.print("Vlozene cislo: ");
    Serial.println(cislo_vstup);
  }
}

Úloha: nastav úhel serva přes Serial Monitor

Signál serva připoj na D9. Při příkazu 90 přejde servo přibližně do střední polohy; při -13 nebo 10000 program vypíše chybu. Pro servo použij vhodné napájení, a pokud má samostatný zdroj, nezapomeň na společnou GND.

Úlohy z původního PDF · bez hotového řešení

Servo ovládané ze sériového monitoru

Nejdřív samostatně napiš program pro nastavení úhlu serva pomocí Serial.parseInt(). Potom doplň kontrolu, která odmítne čísla mimo rozsah 0–180° a vypíše chybovou zprávu.

Ověř: hodnoty 0, 90 a 180° jsou přijaty; −13 a 10000 jsou odmítnuty.

Poznámka ke kontrole vstupu: Funkce Serial.parseInt() nemusí sama odlišit neplatný text od hodnoty nula. Pro spolehlivé ověření úhlu promysli také kontrolu formátu zprávy.

Sériová komunikace mezi dvěma Arduiny

Chceš-li propojit dvě desky přes hardwarový UART, spoj TX jedné desky s RX druhé a RX první desky s TX druhé. Nezapomeň propojit GND ↔ GND. Obě desky musí používat shodnou přenosovou rychlost a kompatibilní logické úrovně.

Důležité pro Arduino Uno / Nano: Hardwarový UART používá piny D0 (RX) a D1 (TX). Tyto piny mohou být zároveň používány USB převodníkem při nahrávání programu či práci se sériovým monitorem. Před nahráváním kódu může být nutné propojení mezi deskami odpojit. Pokud mají desky samostatné USB napájení, nespojuj bez rozmyslu jejich 5V napájecí vývody; propojení GND je pro UART nutné.

Praktická úloha: tři potenciometry řídí RGB LED

Na Arduino A připoj tři potenciometry na analogové vstupy A0, A1, A2. Na Arduino B připoj RGB LED se společnou katodou; každou barvu připoj přes samostatný rezistor (například 220–330 Ω) na PWM piny D9, D10, D11. Po UARTu se odešle trojice intenzit R,G,B v rozsahu 0–255.

Formát zprávy: například 128,40,255 a znak nového řádku. Příjemce zprávu rozdělí na tři čísla a nastaví odpovídající PWM výstupy.

RGB LED – vlastní program pro obě Arduina

První Arduino přečte tři analogové vstupy a odešle čísla oddělená čárkami. Druhé Arduino přečte celý řádek, ověří rozsahy a nastaví PWM výstupy. Kód je určen pro školní zapojení Uno/Nano s RGB LED se společnou katodou.

    Dvě Arduina: RGB přes UART

    Na Arduino A připoj tři potenciometry, na Arduino B RGB LED. Propoj TX/RX do kříže a GND. Pošli trojici R,G,B.

    Kontrola výsledku: Při pohybu potenciometrů se mění odpovídající barvy RGB LED.
    Bezpečnost a zapojení: Před každou změnou propojení odpoj napájení. Při připojení serva dbej na vhodné napájení a společnou zem. U dvou Arduin ověř TX ↔ RX a GND ↔ GND.

    Shrnutí:

    UARTData se přenášejí po bitech. TX vysílá, RX přijímá.
    available()Oznamuje počet bajtů čekajících v přijímacím bufferu.
    readString()Načítá text; při čekání může rozhodovat timeout.
    parseInt()Načítá celé číslo; aplikace musí kontrolovat správný rozsah.
    Dvě deskyPropojit TX ↔ RX, RX ↔ TX a společnou GND.
    PraxeLCD přijímá text, servo úhel a RGB LED tři intenzity.

    Průvodce studiem:

    Začni jednoduchým programem se Serial.available() a sériovým monitorem. Vyzkoušej text i různá ukončení řádku. Potom připoj LCD a servo, u něhož hlídej hranice 0–180°. Nakonec propoj dvě Arduina a odesílej tři hodnoty RGB. Při potížích kontroluj postupně přenosovou rychlost, piny TX/RX, společnou GND a formát zprávy.

    Praktická rada: Po každém kroku nejprve otestuj samostatnou funkci, teprve potom přidej další součástku.

    Kontrolní otázky:

    Nejprve odpověz vlastními slovy. Rozbalením otázky ověříš správnou odpověď.

    1. Co znamená UART?
    Odpověď

    Universal Asynchronous Receiver-Transmitter – hardwarové rozhraní pro asynchronní sériový přenos.

    2. Jaký je rozdíl mezi TX a RX?
    Odpověď

    TX odesílá data; RX přijímá data.

    3. Proč je třeba nastavit stejnou přenosovou rychlost?
    Odpověď

    Vysílač a přijímač musí správně rozpoznat časování jednotlivých bitů.

    4. Co vrací Serial.available()?
    Odpověď

    Počet bajtů dostupných v přijímacím bufferu.

    5. Proč se Serial.available() často používá v podmínce if?
    Odpověď

    Aby se četlo až ve chvíli, kdy jsou k dispozici nějaká data.

    6. K čemu se hodí Serial.readString()?
    Odpověď

    K převzetí textové zprávy ze sériové linky do proměnné typu String.

    7. Co znamená timeout u textového čtení?
    Odpověď

    Maximální čekání na další přicházející data při čtecí operaci.

    8. Jak zobrazíš text na druhém řádku LCD 16 × 2?
    Odpověď

    Přesuň kurzor voláním lcd.setCursor(0, 1) a vypiš text.

    9. Kdy použiješ Serial.parseInt()?
    Odpověď

    Při čtení celého čísla ze sériové linky, např. pro nastavení úhlu serva.

    10. Proč musí program kontrolovat rozsah úhlu serva?
    Odpověď

    Neplatné hodnoty, například −13 a 10000, nemají být předány přímo servu; povolený interval v úloze je 0–180°.

    11. Jak propojíš dvě Arduina přes UART?
    Odpověď

    TX prvního na RX druhého, RX prvního na TX druhého a GND na GND.

    12. Jak se přenáší barvy mezi dvěma Arduiny?
    Odpověď

    První deska přečte tři potenciometry, převede je na 0–255 a odešle např. 128,40,255; druhá nastaví tři PWM kanály RGB LED.

    13. Na co dát pozor při používání pinů D0 a D1 na Arduino Uno?
    Odpověď

    Sdílejí hardwarový sériový port s USB převodníkem; při nahrávání programu a práci s monitorem mohou vznikat konflikty.

    14. Proč mají být propojené země obou desek?
    Odpověď

    Aby UART signály měly společnou referenční úroveň napětí.
