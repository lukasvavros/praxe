Kapitola 5: LCD displej

Praxe – Arduino | 3. ročník

Opakování – parkovací závora

V předchozích kapitolách jsme ovládali LED, četli stav tlačítka a nastavovali polohu servomotoru. Nyní tyto dovednosti spojíme do modelu vjezdu na parkoviště. Program navrhněte sami podle požadovaného chování.

Úloha – parkovací závora se signalizací

Cíl: Zapojte tlačítko, servomotor a dvě LED. Vytvořte program, který po stisknutí tlačítka otevře závoru, umožní průjezd a potom ji opět zavře.

Zapojení

  • Tlačítko: jeden kontakt na pin D2, druhý na GND. V programu použijte režim INPUT_PULLUP.
  • Červená LED: delší vývod přes samostatný rezistor 220 až 330 Ω na pin D6, kratší na GND.
  • Zelená LED: delší vývod přes samostatný rezistor 220 až 330 Ω na pin D7, kratší na GND.
  • Servomotor: řídicí vodič na pin D9. Napájení připojte podle parametrů serva; při použití samostatného zdroje propojte jeho GND s GND Arduina.
  • Na páku serva připevněte lehké papírové rameno závory. Zvolte dvě bezpečné polohy, například 10° pro zavření a 90° pro otevření, a ověřte je podle upevnění ramene.

Požadované chování programu

  1. Po zapnutí je závora zavřená, červená LED svítí a zelená je zhasnutá.
  2. Stisknutí tlačítka zahájí jeden cyklus průjezdu.
  3. Červená LED třikrát zabliká: vždy 300 ms zhasnutá a 300 ms rozsvícená. Závora zatím zůstává zavřená.
  4. Servo zvedne závoru. Během otevírání ponechte červenou LED rozsvícenou. Pro tento model vyhraďte na pohyb přibližně 1 sekundu.
  5. Po otevření červená zhasne a rozsvítí se zelená. Závora zůstane otevřená 4 sekundy.
  6. Zelená zhasne, rozsvítí se červená a servo závoru zavře. Na zavření opět vyhraďte přibližně 1 sekundu.
  7. Po dokončení čeká program na nový stisk. Držení tlačítka nesmí spustit další cyklus; stisky během průjezdu se neukládají.
Důležité: Stisknuté tlačítko s INPUT_PULLUP má hodnotu LOW. Obě LED nesmějí svítit současně. Servo nechte pohybovat bez mechanických překážek. Jde o školní model bez snímače překážky.

Jednotlivé fáze závory

Závora je zavřená. Spusťte průjezd nebo projděte jednotlivé fáze.

1. ČekáníZavřeno · čeká na nový stisk
2. Upozornění3× bliknutí červené · pak otevření
3. PrůjezdOtevřeno · zelená svítí 4 s
4. ZavřeníČervená svítí · návrat do čekání
Kontrola výsledku: Vyzkoušejte krátký stisk, dlouhé držení i stisk během průjezdu. Závora musí po jednom cyklu zůstat zavřená, dokud tlačítko neuvolníte a znovu nestisknete.
Rozšiřující úkol: Připojte potenciometr na A0 a nastavujte jím dobu otevření od 2 do 8 sekund. Hodnotu načtěte při zahájení cyklu, aby se během průjezdu neměnila. Použitou dobu vypište do sériového monitoru.

V další části kapitoly: Až zvládnete LCD displej, můžete závoru doplnit o zprávy „STOP“, „VOLNO“ a odpočet do zavření.

LCD jako výstup Arduina

LCD umožní zobrazit naměřené hodnoty přímo u zařízení. Počítač se sériovým monitorem pak pro čtení údajů nepotřebujete.

16 × 2Dva řádky po šestnácti znacích. Sloupce číslujeme 0–15 a řádky 0–1.
I²C adaptérModul na zadní straně displeje zjednoduší propojení s Arduinem. Připojíme napájení, zem a dva komunikační vodiče.
Co se naučítePřipojit displej, přidat knihovnu a zobrazovat text, odpočet i hodnotu potenciometru.

Čtyři vodiče k displeji

V této kapitole používáme Arduino Uno R3 a běžný 5V znakový LCD 1602 s I²C adaptérem. Zapojení kontrolujte podle popisků svého modulu, nikoli podle pořadí pinů na obrázku.

Pin LCDArduino Uno R3Úloha
GNDGNDSpolečná zem
VCC5 VNapájení 5V modulu
SDAA4 / SDAData
SCLA5 / SCLHodinový signál

Piny označené SDA a SCL u AREF jsou na Uno R3 propojené s A4 a A5. Stačí využít jednu z těchto dvojic. Při přepojování odpojte napájení.

Potenciometr z další úlohy připojte na A0. A4 a A5 už používá displej. Trimr na I²C adaptéru nastavuje kontrast LCD, není to potenciometr pro měření na A0.

Jak probíhá komunikace I²C

Arduino zahajuje komunikaci. Vodičem SDA se přenášejí data a vodič SCL určuje jejich časování. Zařízení rozlišujeme pomocí adres. Dva komunikační vodiče doplňuje společná zem a napájení.

7bitová adresa má 128 možných hodnot, část je ale rezervovaná. Neznamená to, že lze bez omezení připojit 128 zařízení. Záleží také na adresách, délce vedení a elektrických vlastnostech sběrnice.

Arduino UnoSDA · SCLLCD · 0x27
  1. START
  2. Adresa + zápis
  3. ACK
  4. Data + ACK
  5. STOP

Klikněte na Další krok a sledujte komunikaci.

Zjednodušený model přenosu. Adaptér převádí data na signály LCD; jeden znak obvykle vyžaduje více přenosů. Ukázka nepředstavuje přesný průběh bitů ani skutečnou rychlost.

Přidání knihovny

Ukázky níže používají variantu LiquidCrystal_I2C z repozitáře johnrickman, která má metody init() a backlight().

  1. Stáhněte ZIP této knihovny přes nabídku Code → Download ZIP v jejím repozitáři.
  2. V Arduino IDE otevřete Sketch → Include Library → Add .ZIP Library… a vyberte stažený ZIP.
  3. Otevřete příklad dodaný s knihovnou a ověřte, že se přeloží pro Uno.
  4. V programu nastavte skutečnou adresu svého adaptéru. 0x27 je příklad, nikoli zaručená adresa každého LCD.
Existuje více knihoven stejného názvu. Nekombinujte jejich příklady. V této variantě použijte lcd.init();; jiné varianty mohou vyžadovat jiný tvar begin().

První text a základní příkazy

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("Ahoj, svete!");
}

void loop() {
}
PříkazVýznam
lcd.init()Připraví displej; patří do setup().
lcd.backlight()Zapne podsvícení.
lcd.setCursor(0, 1)Nastaví začátek druhého řádku.
lcd.print("Text")Zapíše text od aktuální pozice.
lcd.clear()Smaže displej a vrátí kurzor na začátek.

Používejte zatím text bez diakritiky: běžný LCD nemá stejné kódování jako web. Po vypsání kratšího textu zůstávají původní znaky, které jste nepřepsali. Pomohou mezery nebo vymazání řádku. Časté clear() v loop() může způsobit blikání.

Vyzkoušejte LCD

Nejprve předpovězte výsledek, potom jej ověřte. Simulace ukazuje chování displeje; program pro úlohy vytvoříte sami.

Připraveno.

Zkuste nejprve zapsat 100 a potom ze stejné pozice 9. Co zůstane? Ukázka zapisuje jen do konce zvoleného viditelného řádku; skutečný LCD má i skrytou paměť.

Odpočet mění číslo každých 500 ms. Nula zůstane půl sekundy, potom se objeví vzkaz.

Výsledek odpovídá celočíselnému map() z rozsahu 0–1023 na 0–100.

Samostatné úlohy

1 · Vizitka

Zobrazte své jméno na prvním řádku a příjmení na druhém. Každý text má nejvýše 16 znaků, bez diakritiky. Po resetu se vizitka znovu objeví.

Nápověda

Které příkazy stačí provést jednou? Jaké jsou souřadnice začátku druhého řádku?

2 · Odpočet

Po resetu zobrazte postupně čísla 10 až 0 včetně. Každé číslo má být viditelné 0,5 s. Pak zobrazte vlastní vzkaz a ponechte jej na displeji. Při přechodu 10 → 9 nesmí zůstat nula.

Nápověda

Potřebujete odpočet opakovat v loop()? Jak přepíšete oba znaky předchozí hodnoty?

3 · Potenciometr

Zapojte krajní vývody potenciometru na 5 V a GND, jezdec na A0. Na prvním řádku zobrazte popisek, na druhém polohu 0–100 %. Údaj aktualizujte přibližně desetkrát za sekundu. Ověřte krajní polohy i přechod 100 → 9 %.

Nápověda

Využijte převod rozsahu z kapitoly o servu a PWM. Co se stane při zápisu kratšího čísla?

Rozšíření · ovládací panel

Zobrazujte na LCD současně ADC a hodnotu PWM pro LED na D6. Tlačítkem D2 s INPUT_PULLUP přepínejte na druhou obrazovku s požadovaným úhlem serva. Jedno stisknutí smí přepnout obrazovku jen jednou. Pokud připojíte i servo, zvolte bezpečný rozsah a společnou zem; s knihovnou Servo na Uno nepoužívejte PWM na D9 a D10.

Kontrola: Ukažte funkční zapojení, vysvětlete převod rozsahu a předveďte, že po kratších číslech nezůstávají staré znaky.

Řešení po dokončení úloh

Nejprve odevzdejte vlastní pokus. Řešení slouží k porovnání postupu po domluvě s vyučujícím.

Řešení úlohy 2
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.print("Odpocet:");
  for (int cislo = 10; cislo >= 0; cislo--) {
    lcd.setCursor(0, 1);
    lcd.print("                ");
    lcd.setCursor(0, 1);
    lcd.print(cislo);
    delay(500);
  }
  lcd.clear();
  lcd.print("Hotovo!");
}
void loop() {}
Řešení úlohy 3
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
  lcd.print("Poloha:");
}
void loop() {
  int hodnota = analogRead(A0);
  int procenta = map(hodnota, 0, 1023, 0, 100);
  lcd.setCursor(0, 1);
  if (procenta < 100) lcd.print(" ");
  if (procenta < 10) lcd.print(" ");
  lcd.print(procenta);
  lcd.print(" %");
  delay(100);
}

Pomůcka: I²C skener

Připojte samotný LCD adaptér, nahrajte program a otevřete sériový monitor na 9600 baudů. Pokud výpis nestihnete, stiskněte RESET. Nalezená adresa potvrzuje odpověď zařízení, nikoli jeho typ. Po kontrole nahrajte zpět program pro LCD.

#include <Wire.h>
void setup() {
  Serial.begin(9600);
  Wire.begin();
  byte nalezeno = 0;
  for (byte adresa = 8; adresa < 120; adresa++) {
    Wire.beginTransmission(adresa);
    if (Wire.endTransmission() == 0) {
      Serial.print("Nalezeno: 0x");
      if (adresa < 16) Serial.print("0");
      Serial.println(adresa, HEX);
      nalezeno++;
    }
  }
  if (nalezeno == 0) Serial.println("Zadne zarizeni.");
}
void loop() {}
