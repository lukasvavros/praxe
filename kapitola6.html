Kapitola 6: Teplotní a vlhkostní čidlo DHT11

Praxe – Arduino | 3. ročník

Po nastudování této kapitoly budete schopni:

  • Připojit modul DHT11 a rozlišit napájecí a datový pin.
  • Popsat rozdíl mezi digitálním údajem z čidla a analogovou hodnotou potenciometru.
  • Nainstalovat knihovnu DHTlib a ověřit výsledek čtení.
  • Zobrazit teplotu a relativní vlhkost v sériovém monitoru a na LCD.
  • Vytvořit vlastní znak stupně a uchovávat minimum a maximum.
  • Nastavit teplotní limit potenciometrem a zobrazit varování.

Klíčová slova kapitoly:

DHT11, teplota, relativní vlhkost, °C, % RH, VCC, GND, DATA, digitální komunikace, DHTlib, read11(), DHTLIB_OK, interval měření, Serial, LCD, createChar(), minimum, maximum, limit, map(), millis().

Opakování – parkovací závora s LCD

Spojte známé součástky do jednoho projektu: tlačítko spustí průjezd, servo zvedne závoru, LED ukážou stav a LCD zobrazí odpočet. Program nejprve navrhněte sami podle požadovaného chování.

Úloha – otevři, odpočítej, zavři

Cíl: Po novém stisku tlačítka plynule otevřít závoru, povolit průjezd na 5 sekund a potom ji plynule zavřít.

Zapojení

  • Tlačítko D2–GND, v programu INPUT_PULLUP.
  • Servo: signál D9, napájení 5 V a GND podle přiloženého schématu.
  • Červená LED D6, zelená LED D7, každá přes vlastní rezistor 220–330 Ω; katody na GND.
  • LCD s I²C: VCC na 5 V, GND na GND, SDA na A4 a SCL na A5. Ověřte adresu displeje.

Požadované chování

  1. Po zapnutí je závora zavřená (0°). Svítí červená LED, LCD ukazuje „STOP“ a výzvu ke stisku.
  2. Nový stisk spustí otevírání z 0° na 90° během 2 s. Červená stále svítí, LCD ukazuje „Oteviram...“.
  3. Po otevření červená zhasne a zelená se rozsvítí. LCD ukazuje „VOLNO“ a odpočítá 5, 4, 3, 2, 1 sekundu.
  4. Zelená zhasne a červená se rozsvítí. Servo se během 2 s vrátí na 0° a LCD ukazuje „Zaviram...“.
  5. Po zavření se obnoví úvodní stav. Další cyklus vyžaduje uvolnění a nový stisk tlačítka.

Kontrola: Držení tlačítka ani další stisky během pohybu a odpočtu nesmějí restartovat cyklus. Zkontrolujte, že nikdy nesvítí obě LED současně.

Rozšíření: Vytvořte řešení s millis(), aby program průběžně sledoval tlačítko i během pohybu a odpočtu.

Ukázkové řešení – parkovací závora

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);
Servo zavora;
const byte TLACITKO = 2, SERVO_PIN = 9;
const byte CERVENA = 6, ZELENA = 7;
enum Faze { ZAVRENO, OTEVIRANI, VOLNO, ZAVIRANI };
Faze faze = ZAVRENO;
unsigned long zacatek = 0, zmenaTlacitka = 0, posledniLCD = 0;
bool minuleCteni = HIGH, stabilni = HIGH;

void radek(byte cislo, const char *text) {
  lcd.setCursor(0, cislo);
  byte i = 0;
  while (text[i] && i < 16) lcd.write(text[i++]);
  while (i++ < 16) lcd.write(' ');
}

void setup() {
  pinMode(TLACITKO, INPUT_PULLUP);
  pinMode(CERVENA, OUTPUT);
  pinMode(ZELENA, OUTPUT);
  zavora.attach(SERVO_PIN);
  zavora.write(0);
  digitalWrite(CERVENA, HIGH);
  digitalWrite(ZELENA, LOW);
  lcd.init();
  lcd.backlight();
  radek(0, "STOP");
  radek(1, "Stiskni tlacitko");
}

void loop() {
  unsigned long ted = millis();
  bool cteni = digitalRead(TLACITKO);
  if (cteni != minuleCteni) zmenaTlacitka = ted;
  minuleCteni = cteni;
  if (ted - zmenaTlacitka >= 30 && cteni != stabilni) {
    stabilni = cteni;
    // Reagujeme jen na novy stisk a pouze u zavrene zavory.
    if (stabilni == LOW && faze == ZAVRENO) {
      faze = OTEVIRANI;
      zacatek = ted;
    }
  }

  unsigned long uplynulo = ted - zacatek;
  int uhel = 0;
  if (faze == OTEVIRANI) {
    if (uplynulo >= 2000) {
      faze = VOLNO; zacatek = ted; uplynulo = 0; uhel = 90;
    } else uhel = uplynulo * 90UL / 2000UL;
  } else if (faze == VOLNO) {
    uhel = 90;
    if (uplynulo >= 5000) {
      faze = ZAVIRANI; zacatek = ted; uplynulo = 0;
    }
  } else if (faze == ZAVIRANI) {
    if (uplynulo >= 2000) {
      faze = ZAVRENO; uhel = 0;
    } else uhel = 90 - uplynulo * 90UL / 2000UL;
  }
  zavora.write(uhel);
  digitalWrite(ZELENA, faze == VOLNO ? HIGH : LOW);
  digitalWrite(CERVENA, faze == VOLNO ? LOW : HIGH);

  if (ted - posledniLCD >= 100) {
    posledniLCD = ted;
    if (faze == ZAVRENO) {
      radek(0, "STOP"); radek(1, "Stiskni tlacitko");
    } else if (faze == OTEVIRANI) {
      radek(0, "Oteviram..."); radek(1, "Vyckejte");
    } else if (faze == ZAVIRANI) {
      radek(0, "Zaviram..."); radek(1, "Vyckejte");
    } else {
      radek(0, "VOLNO");
      int zbyva = (5000UL - (ted - zacatek) + 999UL) / 1000UL;
      char text[17];
      snprintf(text, sizeof(text), "Zavreni za: %d s", zbyva);
      radek(1, text);
    }
  }
}

Co měří DHT11

DHT11 měří teplotu vzduchu a relativní vlhkost. Elektronika uvnitř čidla převádí měření na čísla a posílá je po pinu DATA. Arduino proto nečte teplotu funkcí analogRead().

Teplotave stupních Celsia · °C
Vlhkostrelativní vlhkost · % RH
DATAdigitální přenos obou hodnot

Relativní vlhkost říká, jak blízko je vzduch nasycení vodní párou při dané teplotě. Hodnota 50 % neznamená, že polovinu vzduchu tvoří voda.

Pro běžný DHT11 z podkladu uvažujeme teplotu 0–50 °C a relativní vlhkost 20–90 % RH, s orientační přesností ±2 °C a ±5 procentních bodů RH. Konkrétní parametry ověřte pro svůj modul. Zobrazení více desetinných míst samo nezpřesní měření.

Zapojení čidla a displeje

V této kapitole pracujeme s třípinovým modulem DHT11. Řiďte se popisky na svém modulu: pořadí pinů se mezi výrobci může lišit.

Pozor na dvě provedení: Samotné čidlo má čtyři vývody (VCC, DATA, nezapojený, GND). Třípinový modul obvykle obsahuje také pull-up rezistor mezi DATA a VCC. U samotného čidla použijte zapojení a odpor podle jeho dokumentace. DHT11 nepoužívá I²C; SDA/SCL patří LCD.

Před zapojením DHT11 odpojte opakovací tlačítko z D2. Potenciometr budete potřebovat až pro úlohu s nastavitelným limitem.

Přidání knihovny DHTlib

Knihovna řeší časování digitální komunikace. V celé kapitole používáme DHTlib – Rob Tillaart a hlavičku <dht.h>. Příklady jiných knihoven mohou mít jiné názvy funkcí.

  1. V Arduino IDE otevřete správce knihoven Library Manager.
  2. Vyhledejte DHTlib, ověřte autora Rob Tillaart a knihovnu nainstalujte.
  3. V nabídce příkladů najděte příklad pro DHT11. Nastavte datový pin na D2.
  4. Ověřte program, vyberte Arduino Uno a správný port, potom jej nahrajte.
  5. Otevřete sériový monitor a nastavte 9600 baudů, stejně jako v programu.

Pro LCD použijte stejnou knihovnu LiquidCrystal_I2C jako v kapitole 5. Adresu 0x27 v příkladech případně nahraďte adresou zjištěnou I²C skenerem.

Od měření k číslu

Nejdříve požádejte o měření, potom ověřte jeho stav a až při úspěchu použijte teplotu a vlhkost.

int stav = cidlo.read11(2);
if (stav == DHTLIB_OK) {
  float teplota = cidlo.temperature;
  float vlhkost = cidlo.humidity;
}

Arduino vyvolá komunikaci s čidlem na D2.

V úlohách provádějte čtení jednou za 2 sekundy. Pro začátek postačí delay(2000). Pokud má potenciometr reagovat i mezi měřeními, oddělte načítání čidla pomocí millis().

Chyba není naměřená nula. Neúspěšné čtení nesmí přepsat minimum či maximum ani vyvolat závěr, že je teplota v pořádku. Zobrazte informaci o chybě.

Vyzkoušejte měřicí stanici

Změňte prostředí a předpovězte další výsledek. Posuvníky představují okolí čidla, naměřené údaje se aktualizují až při čtení. V režimu limitu přibude potenciometr.

Zobrazení na LCD, extrémy a limit

Dva řádky pro dvě veličiny

Na první řádek zapište teplotu, na druhý vlhkost. Po kratší hodnotě přepište zbylé pozice mezerami. Nemusíte při každém měření mazat celý displej funkcí clear().

Vlastní znak stupně

LCD nemusí rozumět znaku ° vloženému přímo do textu programu. Vytvořte vlastní znak 5 × 8 bodů, uložte jej do pozice 0 pomocí createChar() a vypište jej pomocí lcd.write(byte(0)).

byte stupen[8] = {
  0b00110, 0b01001, 0b01001, 0b00110,
  0b00000, 0b00000, 0b00000, 0b00000
};
// V setup() po lcd.init():
lcd.createChar(0, stupen);
// Pri vypisu za teplotou:
lcd.write(byte(0));
lcd.print("C");

Minimum a maximum

Obě proměnné nastavte podle prvního platného měření. Při dalším čtení minimum snižte jen při nižší hodnotě a maximum zvyšte jen při vyšší hodnotě. Chybné čtení extrémy nemění.

Nastavitelný limit

Hodnotu analogRead(A0) převeďte z rozsahu 0–1023 na 10–40 °C. Varování zobrazte při teplota > limit. Při rovnosti limit překročen není.

Vyzkoušejte hranici: Teplota 25 °C, limit 25 °C → bez varování. Teplota 26 °C, limit 25 °C → varování. Při chybě čidla se zobrazí chyba, nikoli „V pořádku“.

Samostatné úlohy

Bez potenciometru

1. Připravte knihovnu

Zadání: Nainstalujte DHTlib od Roba Tillaarta, najděte příklad pro DHT11 a určete místo, kde se nastavuje datový pin.

Kontrola: Příklad projde ověřením a umíte vysvětlit, proč nelze libovolně zaměňovat příklady různých knihoven.

2. Měřte do sériového monitoru

Zadání: Zapojte DHT11 na D2. Každé 2 s vypište teplotu a vlhkost včetně jednotek. Neplatné čtení nahraďte chybovým hlášením.

Kontrola: Monitor má rychlost 9600 baudů. Chyba se nevypisuje jako teplota 0 °C.

3. Přidejte LCD

Zadání: Na prvním řádku LCD zobrazte teplotu, na druhém relativní vlhkost. Zachovejte dvousekundový interval měření.

Kontrola: Po změně delšího čísla na kratší nezůstávají na LCD staré znaky.

4. Vytvořte znak stupně

Zadání: Navrhněte vlastní znak ° v mřížce 5 × 8. Přidejte jej za číselnou teplotu a doplňte písmeno C.

Kontrola: Znak se zobrazí jako jediný znak LCD a neposune zbytek řádku mimo displej.

5. Sledujte minimum a maximum

Zadání: Na prvním řádku zobrazte aktuální teplotu, na druhém nejnižší a nejvyšší teplotu od spuštění.

Kontrola: První platné měření inicializuje oba extrémy; chybné čtení je nemění.

S potenciometrem

6. Nastavte teplotní limit

Zadání: Přidejte potenciometr na A0 a nastavujte jím limit 10–40 °C. Na LCD zobrazte teplotu i limit a při překročení varování. Potenciometr má reagovat i mezi měřeními čidla.

Kontrola: Čidlo se čte každé 2 s, limit se mění průběžně. Otestujte teplotu pod limitem, přesně na limitu, nad limitem a chybu čtení.

Rozšíření: Přidejte LED pro překročení limitu. Potom navrhněte, jak zabránit opakovanému přepínání varování při kolísání teploty těsně kolem limitu.

Řešení po dokončení úloh

Nejprve vytvoř vlastní řešení.

Porovnej chování se simulací, ověř zapojení a vysvětli svůj program. Ukázku otevři až po domluvě s vyučujícím.

Úloha 6 – nastavitelný limit
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <dht.h>

dht cidlo;
LiquidCrystal_I2C lcd(0x27, 16, 2); // Adresu overte skenerem.
const byte DHT_PIN = 2;
const byte POT_PIN = A0;
unsigned long posledni = 0;
float teplota = 0;
bool platne = false;

void radek(byte r) {
  lcd.setCursor(0, r);
  lcd.print("                ");
  lcd.setCursor(0, r);
}

void setup() {
  Serial.begin(9600);
  lcd.init();
  lcd.backlight();
  posledni = millis() - 2000UL;
}

void loop() {
  unsigned long ted = millis();
  if (ted - posledni >= 2000UL) {
    posledni = ted;
    int stav = cidlo.read11(DHT_PIN);
    platne = (stav == DHTLIB_OK);
    if (platne) teplota = cidlo.temperature;
    else Serial.println("Chyba cidla");
  }
  int limit = map(analogRead(POT_PIN), 0, 1023, 10, 40);
  radek(0);
  if (!platne) {
    lcd.print("Chyba cidla");
    radek(1); lcd.print("Zkontroluj DATA");
  } else {
    lcd.print("T:"); lcd.print(teplota, 0);
    lcd.print("C L:"); lcd.print(limit); lcd.print("C");
    radek(1);
    if (teplota > limit) lcd.print("POZOR: T > LIMIT");
    else lcd.print("V poradku");
  }
  delay(100); // LCD/limit po 100 ms; DHT stale jen po 2 s.
}

Když měření nefunguje

Shrnutí:

V této kapitole jste se dozvěděli, jak digitální čidlo DHT11 měří teplotu a relativní vlhkost a jak jeho údaje přečíst pomocí knihovny. Umíte rozlišit platné měření od chyby, zobrazit data v sériovém monitoru i na LCD a vytvořit vlastní znak stupně. Naučili jste se uchovávat nejnižší a nejvyšší naměřenou teplotu a porovnávat ji s limitem nastaveným potenciometrem.

Průvodce studiem:

Začněte parkovací závorou a zopakujte si ovládání serva, čtení tlačítka, LED, časování a práci s LCD. Potom zprovozněte samotné čidlo se sériovým monitorem. LCD připojte až po úspěšném čtení. Nakonec přidejte extrémy a limit. U každé úlohy si nejprve napište očekávaný výsledek a vyzkoušejte také chybu nebo mezní hodnotu.

Kontrolní otázky:

1. Co měří DHT11 a v jakých jednotkách?
Odpověď

Teplotu ve °C a relativní vlhkost v % RH.

2. Co znamená relativní vlhkost 50 %?
Odpověď

Vzduch obsahuje přibližně polovinu množství vodní páry odpovídajícího nasycení při dané teplotě. Neznamená to, že polovinu vzduchu tvoří voda.

3. K čemu slouží VCC, GND a DATA?
Odpověď

VCC napájí modul, GND tvoří společnou zem a DATA přenáší digitální údaje.

4. Má každý DHT11 pouze tři vývody?
Odpověď

Ne. Samotné čidlo má čtyři vývody, jeden je nezapojený. Třípinový modul má vyvedené VCC, DATA a GND.

5. Proč se nelze řídit pouze pořadím pinů na cizím obrázku?
Odpověď

Různé moduly mohou mít jiné pořadí. Rozhodují popisky a dokumentace konkrétního modulu.

6. Lze teplotu DHT11 číst pomocí analogRead()?
Odpověď

Ne. Čidlo posílá digitální data. analogRead() zde používáme pro jezdec potenciometru.

7. Používají DHT11 a LCD stejnou sběrnici?
Odpověď

Ne. DHT11 má vlastní digitální komunikaci po DATA. LCD adaptér v kapitole používá I²C, tedy SDA a SCL.

8. Kterou knihovnu používáme a jakou hlavičku přidáme?
Odpověď

DHTlib od Roba Tillaarta a #include <dht.h>.

9. Co vrací read11() a kde jsou naměřené hodnoty?
Odpověď

Vrací stav čtení. Hodnoty získáme z temperature a humidity objektu čidla až po ověření úspěchu.

10. Co znamená DHTLIB_OK?
Odpověď

Čtení proběhlo úspěšně a lze zpracovat získané údaje.

11. Jak se zachovat při chybě čtení?
Odpověď

Oznámit chybu a nepoužít neplatnou hodnotu pro LCD, extrémy ani vyhodnocení limitu.

12. Proč v úlohách čteme čidlo jednou za dvě sekundy?
Odpověď

Čidlo nepotřebuje rychlé opakované dotazování. Interval ponechává čas mezi čteními a odpovídá příkladům používaným v kapitole.

13. Co musí souhlasit u sériového monitoru?
Odpověď

Komunikační rychlost s hodnotou v Serial.begin(), zde 9600 baudů.

14. Na které piny Uno patří SDA a SCL?
Odpověď

SDA na A4 a SCL na A5. Jezdec potenciometru je na A0.

15. Proč tisk dvou desetinných míst nezlepší přesnost?
Odpověď

Formát výpisu nezmění vlastnosti čidla. Přesnost určuje měření a parametry senzoru.

16. Jak zabráníte zbytkům starých znaků na LCD?
Odpověď

Přepíšete zbytek řádku mezerami nebo používáte stálou šířku výpisu.

17. Jak vypíšete vlastní znak uložený na pozici 0?
Odpověď

Po vytvoření znakové bitmapy pomocí createChar() použijete lcd.write(byte(0)).

18. Jak inicializujete minimum a maximum?
Odpověď

Obě proměnné nastavíte na první platně naměřenou teplotu.

19. Měření jsou 24, 21, 27 a 23 °C. Jaké jsou extrémy?
Odpověď

Minimum je 21 °C, maximum 27 °C a aktuální teplota 23 °C.

20. Teplota je 25 °C a limit 25 °C. Aktivuje se teplota > limit?
Odpověď

Ne. Rovnost není překročení. Při 26 °C už podmínka platí.

21. Jak vznikne limit z hodnoty potenciometru?
Odpověď

Pomocí map() převedeme 0–1023 na 10–40 °C. V této úloze je výsledek celočíselný.

22. Proč může delay(2000) vadit ovládání limitu?
Odpověď

Blokuje hlavní smyčku, takže se během čekání nečte potenciometr. Pomocí millis() lze čidlo číst pomalu a ovládání obsluhovat průběžně.

23. Proč opakovací tlačítko při stisku vrací LOW?
Odpověď

INPUT_PULLUP udržuje uvolněný vstup HIGH; stisk jej spojí s GND.

24. Co ověříte před připojením čidla na D2 po opakování?
Odpověď

Že je od D2 odpojeno tlačítko. Stejný pin zde nemůže současně sloužit tlačítku a DATA čidla.
