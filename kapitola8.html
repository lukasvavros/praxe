Kapitola 8: Ultrazvukový senzor HC-SR04

Praxe – Arduino | 3. ročník

Po nastudování této kapitoly budete schopni:

  • Popsat měření vzdálenosti pomocí odraženého zvuku.
  • Zapojit HC-SR04 a rozlišit piny TRIG a ECHO.
  • Změřit délku impulzu a převést mikrosekundy na centimetry.
  • Rozpoznat neplatné měření a ošetřit timeout.
  • Zobrazit vzdálenost na LCD a řídit jas LED.

Klíčová slova kapitoly:

Ultrazvuk, HC-SR04, TRIG, ECHO, odraz, doba letu, mikrosekunda, pulseIn(), timeout, vzdálenost, LCD, PWM, map(), constrain().

Opakování – světlo s pamětí

Úloha – osvětlení za šera

Použijte dělič z kapitoly 7: 5 V → fotorezistor → A0 → rezistor 1 kΩ → GND. LED připojte anodou přes rezistor 220–330 Ω na D6, katodou na GND.

  • Při ADC ≤ 450 LED rozsviťte. Při ADC ≥ 600 ji zhasněte.
  • Mezi prahy zachovejte předchozí stav. Po spuštění je LED zhasnutá.
  • Do sériového monitoru vypisujte hodnotu ADC. Ověřte průchod pásmem oběma směry.

Nejprve vytvoř vlastní řešení.

const byte LED = 6;
bool sviti = false;
void setup() {
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int svetlo = analogRead(A0);
  if (svetlo <= 450) sviti = true;
  else if (svetlo >= 600) sviti = false;
  digitalWrite(LED, sviti ? HIGH : LOW);
  Serial.println(svetlo);
  delay(100);
}

Jak funguje ultrazvukové měření

Senzor vyšle krátkou dávku zvuku, který se od překážky odrazí. Z doby návratu odrazu určíme vzdálenost. HC-SR04 používá ultrazvuk přibližně 40 kHz, který člověk běžně neslyší.

Modul má vysílač a přijímač. TRIG spouští měření; délka impulzu na ECHO vyjadřuje dobu odpovídající cestě zvuku tam a zpět. Větší vzdálenost znamená delší impulz.

Zvuk urazí dvě cesty: od senzoru k překážce a zpět. Proto výsledek dělíme dvěma.

Pro běžný HC-SR04 se uvádí rozsah přibližně 2–400 cm. Skutečný výsledek závisí na povrchu, natočení překážky a okolních podmínkách. Údaj mimo rozsah nepovažujte za spolehlivé měření.

Zapojení HC-SR04

V této kapitole používáme Arduino Uno s logikou 5 V. Orientujte se podle označení pinů na konkrétním modulu.

Pro úlohu 3 přidejte LCD 16×2 s I²C: VCC → 5 V, GND → GND, SDA → A4 a SCL → A5. Pro úlohu 4 použijte LED na D6 přes vlastní rezistor 220–330 Ω, katodu na GND. LCD pro úlohu 4 není potřeba.

Spuštění měření a signál ECHO

  • TRIG nejprve nastavte na LOW a krátce vyčkejte.
  • Vytvořte impulz HIGH dlouhý 10 µs a potom TRIG vraťte na LOW.
  • Funkcí pulseIn() změřte délku HIGH na ECHO.
  • Před dalším měřením ponechte prodlevu; v ukázkách používáme 100 ms.
digitalWrite(TRIG, LOW);
delayMicroseconds(2);
digitalWrite(TRIG, HIGH);
delayMicroseconds(10);
digitalWrite(TRIG, LOW);
unsigned long doba = pulseIn(ECHO, HIGH, 30000UL);

pulseIn() vrací délku impulzu v mikrosekundách. Třetí argument omezuje čekání; 30 000 µs je 30 ms. Při neúspěšném měření vrátí nulu. Funkce během měření blokuje hlavní běh programu.

Nula není vzdálenost 0 cm. Pokud doba == 0, oznamte neplatné měření. Starou hodnotu na displeji neponechávejte jako aktuální.

Převod času na vzdálenost

Ve výpočtu použijeme přibližnou rychlost zvuku 343 m/s, tedy 0,0343 cm/µs. Rychlost zvuku se mění například s teplotou.

float vzdalenost = doba * 0.0343f / 2.0f;

Příklad: ECHO dlouhé 2 000 µs znamená 2 000 × 0,0343 / 2 = 34,3 cm. Čas dosazujeme v mikrosekundách; nezaměňujte jej s milisekundami.

Před výpočtem ověřte, že doba není nula. Po výpočtu zkontrolujte, zda vzdálenost leží v pracovním rozsahu senzoru.

Samostatné úlohy a simulace

1. Délka impulzu

Zadání: Zapojte senzor a do sériového monitoru vypisujte délku ECHO v µs. Při timeoutu vypište chybové hlášení.

Kontrola: Přibližte a oddalte rovnou překážku. S rostoucí vzdáleností má doba růst.

2. Vzdálenost v centimetrech

Zadání: Převeďte dobu na centimetry a vypisujte výsledek s jedním desetinným místem. Ošetřete timeout a rozsah.

Kontrola: Porovnejte výsledek s pravítkem při několika vzdálenostech.

3. Přenosný dálkoměr s LCD

Zadání: Přidejte LCD a zobrazujte vzdálenost. Při neplatném měření zobrazte „Bez mereni“. Po ověření můžete Arduino napájet přes USB z powerbanky.

Kontrola: Vyzkoušejte rovnou stěnu, šikmou plochu a měkkou látku. Zapište, kdy měření přestává být spolehlivé.

4. Vzdálenost řídí jas LED

Zadání: Použijte PWM na D6. Při 2 cm nastavte 0, od 30 cm výše 255. Mezi nimi měňte jas pomocí map(). Při chybě nebo vzdálenosti pod 2 cm LED zhasněte.

Kontrola: Ověřte hranice 2 a 30 cm a střed 16 cm. V řešení vzdálenost nejprve zaokrouhlujeme na celé cm; map() pracuje s celými čísly.

Pohyb zvuku je výrazně zpomalený. Měřicí hodnoty se aktualizují po dokončení měření. Poloha překážky v obrázku je názorná, nikoli v měřítku.

V úloze 1 sleduj dobu, ve druhé převod, ve třetí LCD a ve čtvrté PWM.

Připraveno.

Nejprve vytvoř vlastní řešení.

Řešení úlohy 1
const byte TRIG = 9, ECHO = 10;
unsigned long zmerCas() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  return pulseIn(ECHO, HIGH, 30000UL);
}
void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
}
void loop() {
  unsigned long doba = zmerCas();
  if (doba == 0) Serial.println("Bez odrazu / timeout");
  else { Serial.print(doba); Serial.println(" us"); }
  delay(100);
}

Řešení úlohy 4
const byte TRIG = 9, ECHO = 10;
unsigned long zmerCas() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  return pulseIn(ECHO, HIGH, 30000UL);
}
void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
  pinMode(6, OUTPUT);
}
void loop() {
  unsigned long doba = zmerCas();
  float cm = doba * 0.0343f / 2.0f;
  bool platne = doba != 0 && cm >= 2.0f && cm <= 400.0f;
  if (platne) { Serial.print(cm, 1); Serial.println(" cm"); }
  else Serial.println("Neplatne mereni");
  int jas = 0;
  if (platne) {
    long celeCm = (long)(cm + 0.5f);
    celeCm = constrain(celeCm, 2L, 30L);
    jas = map(celeCm, 2, 30, 0, 255);
  }
  analogWrite(6, jas);
  delay(100);
}

Když měření nefunguje

  • Stálá nula: zkontrolujte napájení, společnou zem, čísla pinů a záměnu TRIG/ECHO.
  • Nepravidelné výsledky: změňte natočení a povrch překážky, měřte v rozsahu a dodržte prodlevu.
  • LCD bez textu: zkontrolujte kontrast, I²C adresu modulu a propojení SDA/SCL. Adresa 0x27 v ukázce nemusí odpovídat každému modulu.
  • LED bez plynulé změny: zkontrolujte PWM pin D6, polaritu, rezistor a převod rozsahu.
  • map() samo neomezuje výsledek. Proto v ukázce nejprve omezujeme vzdálenost pomocí constrain().

Shrnutí:

V této kapitole jste se dozvěděli, jak z doby návratu ultrazvuku získat vzdálenost. Spustili jste měření přes TRIG, změřili impulz ECHO a ošetřili případ, kdy se použitelný odraz nevrátí. Výsledek jste zobrazili na sériovém monitoru, LCD a převedli na jas LED.

Průvodce studiem:

Postupujte od samotného času k výpočtu a teprve potom přidávejte výstupy. Před každým pokusem odhadněte výsledek. Vytvořte tabulku tří vzdáleností změřených pravítkem a senzorem, porovnejte odchylky a vysvětlete jejich možné příčiny.

Kontrolní otázky:

1. Jaký je princip měření?
Odpověď

Měří se doba odpovídající cestě zvuku k překážce a zpět.

2. Proč dělíme výpočet dvěma?
Odpověď

Naměřený čas zahrnuje obě cesty, ale hledáme jednosměrnou vzdálenost.

3. Který pin spouští měření?
Odpověď

TRIG, v této kapitole D9.

4. Je ECHO z pohledu Arduina vstup, nebo výstup?
Odpověď

Vstup, na D10 s režimem INPUT.

5. Jak dlouhý impulz posíláme na TRIG?
Odpověď

10 mikrosekund.

6. Co vrací pulseIn()?
Odpověď

Délku impulzu v mikrosekundách; při neúspěchu nulu.

7. Znamená nula z pulseIn() překážku ve vzdálenosti 0 cm?
Odpověď

Ne, znamená neúspěšné měření.

8. Kolik milisekund je 30 000 µs?
Odpověď

30 ms.

9. Jak spočítáte vzdálenost?
Odpověď

Čas v µs krát 0,0343 děleno dvěma dává cm.

10. Jaká vzdálenost odpovídá 2 000 µs?
Odpověď

34,3 cm při použité rychlosti zvuku.

11. Co se děje s ECHO při vzdalování překážky?
Odpověď

Jeho délka při platném odrazu roste.

12. Proč čekáme mezi měřeními?
Odpověď

Aby předchozí zvuk a odrazy co nejméně rušily další měření.

13. Proč může šikmá plocha zhoršit měření?
Odpověď

Zvuk se může odrazit mimo přijímač.

14. Proč není každé měření přesné na milimetr?
Odpověď

Výsledek ovlivňují podmínky, povrch, úhel, teplota i vlastnosti modulu.

15. Kam připojíme LCD SDA a SCL na Uno?
Odpověď

SDA na A4, SCL na A5.

16. Co má LCD ukázat při neplatném výsledku?
Odpověď

Chybové hlášení, například Bez mereni, místo staré vzdálenosti.

17. Jaký rozsah používá analogWrite()?
Odpověď

0–255 na PWM pinu Uno.

18. Co udělá LED při 2 a 30 cm?
Odpověď

Při 2 cm je PWM 0; při 30 cm PWM 255.

19. Jaké PWM vyjde pro 16 cm pomocí map(16, 2, 30, 0, 255)?
Odpověď

127; celočíselný výpočet odřízne desetinnou část.

20. Proč před map() používáme constrain()?
Odpověď

map() neomezuje výstup na požadovaný rozsah; constrain() omezí vstup.

21. Co se stane s LED při timeoutu?
Odpověď

V našem řešení zhasne.

22. Jak opravíte nastavení pinMode(ECHO, OUTPUT)?
Odpověď

Změnou na pinMode(ECHO, INPUT).
