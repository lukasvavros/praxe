DIGITÁLNÍ VÝSTUP · ČASOVÁNÍ

Tři LED. Každá má svůj okamžik.

Nejdříve střídej LED na desce a červenou LED. Potom přidej zelenou. Vždy svítí právě jedna LED po dobu 1 sekundy.

Na desce · D13LOW · 0
Červená · D3LOW · 0
Zelená · D2LOW · 0

Připraveno. Spusť animaci nebo vyzkoušej jednotlivé kroky.

1 · D132 · D33 · D2

Nejprve vytvoř vlastní řešení.

Vyzkoušej chování obvodu a napiš program. Řešení si zobraz až po domluvě s vyučujícím.

Řešení: dvě LED

const int cervena = 3;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(cervena, OUTPUT);
  pinMode(2, OUTPUT);
  digitalWrite(2, LOW);  // Zelená LED zatím zůstává zhasnutá.
}

void loop() {
  digitalWrite(cervena, LOW);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  digitalWrite(cervena, HIGH);
  delay(1000);
}
const int cervena = 3;
const int zelena = 2;

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  pinMode(cervena, OUTPUT);
  pinMode(zelena, OUTPUT);
}

void loop() {
  digitalWrite(zelena, LOW);
  digitalWrite(LED_BUILTIN, HIGH);
  delay(1000);

  digitalWrite(LED_BUILTIN, LOW);
  digitalWrite(cervena, HIGH);
  delay(1000);

  digitalWrite(cervena, LOW);
  digitalWrite(zelena, HIGH);
  delay(1000);
}

Ve schématu má každá externí LED vlastní rezistor. Vestavěnou LED najdeš na desce u označení L.
