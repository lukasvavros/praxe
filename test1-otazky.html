Praxe – Arduino | 3. ročník · všechny úlohy bez odpovědí

O testu

Na této stránce je všech 62 úloh, ze kterých se losuje ostrý test z kapitoly 1 – Úvod do Arduina. Každý žák dostane 17 úloh, takže se zadání mezi spolužáky liší. Odpovědi tu nejsou, ověř si je ve výkladu kapitoly.

Test má 45 bodů. Na testu je 6 znalostních otázek, 3 chyby v kódu, 3 doplňovačky, 1 slovní úloha a 4 schémata zapojení. Schémata a slovní úlohu hodnotí vyučující.
  • A. Znalosti: 22 otázek v bance, na testu 6 × 1 bod
  • B. Najdi chybu: 11 úloh v bance, na testu 3 × 2 body
  • C. Doplň kód: 12 úloh v bance, na testu 3 × 3 body
  • D. Slovní úloha: 4 úlohy v bance, na testu 1 × 4 body
  • E. Schémata: 13 zadání v bance, na testu 4 × 5 bodů

B. Najdi chybu v kódu

V každém programu je jedna chyba. Na testu klikneš na chybný řádek a napíšeš správnou hodnotu nebo název příkazu.

23. LED je připojená anodou přes rezistor na D7 a katodou na GND. V programu je jediná chyba. Klikni na chybný řádek a napiš správnou hodnotu.
int led = 7;void setup() {  pinMode(led, INPUT);}void loop() {  digitalWrite(led, HIGH);  delay(1000);}
24. Program má rozsvítit vestavěnou LED. V kódu je jeden překlep, kvůli kterému se nepřeloží.
void setup() {  pinMode(13, OUTPUT);}void loop() {  digitalWrite(13, HIG);  delay(1000);}
25. Externí LED je fyzicky připojená k pinu D3 (anoda přes rezistor, katoda na GND). Najdi chybu, kvůli které program ovládá jiný pin.
const int led = 2;void setup() {  pinMode(led, OUTPUT);}void loop() {  digitalWrite(led, HIGH);}
26. Program má otevřít sériovou komunikaci 9600 baudů. V kódu je jediná chyba v názvu metody.
void setup() {  Serial.beginn(9600);}void loop() {  Serial.println("Ahoj");  delay(1000);}
27. LED je na D8. Pin je správně nastavený, ale rozsvěcení míří na jiný pin. Najdi chybný řádek.
void setup() {  pinMode(8, OUTPUT);}void loop() {  digitalWrite(9, HIGH);  delay(1000);  digitalWrite(8, LOW);}
28. V sériovém monitoru se má opakovaně vypisovat číslo 5, vždy na nový řádek. Jeden název metody je chybný.
int cislo = 5;void setup() {  Serial.begin(9600);}void loop() {  Serial.printn(cislo);  delay(500);}
29. LED má vždy svítit jednu sekundu a jednu sekundu být zhasnutá. Pouze jedna prodleva je špatně.
void setup() {  pinMode(13, OUTPUT);}void loop() {  digitalWrite(13, HIGH);  delay(100);  digitalWrite(13, LOW);  delay(1000);}
30. Cyklem chceme vypsat 0 až 15 VČETNĚ. Program má pouze jednu logickou chybu.
void setup() {  Serial.begin(9600);  for (int i = 0; i < 15; i++) {    Serial.println(i);  }}void loop() {}
31. Monitor je nastavený na 9600 baudů, ale kód zahajuje komunikaci jinou rychlostí.
void setup() {  Serial.begin(960);}void loop() {  Serial.println("LED sviti");  delay(1000);}
32. Program má nastavit D8 jako výstup. Jeden příkaz má špatně napsaná velká a malá písmena.
void setup() {  pinmode(8, OUTPUT);}void loop() {  digitalWrite(8, HIGH);  delay(500);}
33. Externí LED na D8 má trvale svítit. V jednom příkazu je místo zapnutí uveden opačný logický stav.
void setup() {  pinMode(8, OUTPUT);}void loop() {  digitalWrite(8, LOW);  delay(1000);}

C. Doplň kód

V programu chybí tři místa, označená (1), (2) a (3). Dodrž velká a malá písmena jazyka Arduino.

34. Doplň tři části programu tak, aby vestavěná LED svítila 1 s a potom 1 s nesvítila.
void setup() {
  pinMode(13, (1));
}
void loop() {
  digitalWrite(13, (2));
  delay((3));
  digitalWrite(13, LOW);
  delay(1000);
}
35. Doplň příkazy pro sériový monitor. Nejprve se vypíše text „Ahoj“, potom číslo 13 a nový řádek.
void setup() {
  Serial.(1)(9600);
}
void loop() {
  Serial.(2)("Ahoj");
  Serial.(3)(13);
  delay(1000);
}
36. Externí LED je připojená na D3, anoda přes rezistor, katoda na GND. Po startu má svítit.
const int led = (1);
void setup() {
  pinMode(led, (2));
}
void loop() {
  digitalWrite(led, (3));
}
37. Doplň střídání červené LED na D3 a zelené na D2. V každé fázi svítí přesně jedna LED po 1 s.
void setup() {

  pinMode(2, OUTPUT);
}
void loop() {
  digitalWrite(3, HIGH);
  digitalWrite(2, (1));
  delay((2));
  digitalWrite(3, (3));
  digitalWrite(2, HIGH);
  delay(1000);
}
38. U proměnné byte vytvoř výpis počítadla, které začíná na 250 a po 255 přeteče na 0.
